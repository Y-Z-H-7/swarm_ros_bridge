# nuc2 发送侧优先级调度初版

2026-11-17 在 nuc2 的 `~/swarm_ros_bridge_ws/src/swarm_ros_bridge` 部署了发送侧初版。默认 `~scheduler/enabled=false`，现有 `bridge_drone3.launch` 未开启调度；只有隔离测试配置显式开启。原源码及可执行文件备份在 nuc2 的 `~/swarm_ros_bridge_ws/scheduler_backup_20261117/`。

## 已实现

- 按发送话题名称分为 P0 指令、P1 机间时效消息、P2 电量/位姿、P3 地图和 P4 可视化。状态、轨迹、遥测、地图清单与整图使用最新值队列；事件、地图块和 Marker 使用有界 FIFO。
- ROS 回调先沿用原有 `max_freq`，随后序列化入队；单独线程创建并独占发送 PUB socket。P0 优先，其余队列按 P1:P2:P3:P4 = 8:4:2:1 的字节权重轮转，由全局字节令牌桶限制提交速率。
- 每话题限制待发消息数和字节数；过大、超过桶突发上限或队列满时记录拒绝，最新值覆盖计数和发送计数定期写入 ROS 日志。
- 私有参数：`~scheduler/enabled`、`~scheduler/budget_bytes_per_second`、`~scheduler/burst_bytes`。开启时后两者必须大于零；`burst_bytes` 必须大于需要发送的单帧大小。

## 隔离测试

测试配置只包含 `/bridge_test/*` 三类非控制话题，使用独立 ROS master 和 5511–5513 测试端口。nuc2 经当前 Wi-Fi 向有线地面站发送模拟状态、电量与 100 KB 点云；预算设为 50,000 B/s，突发上限 524,288 B。地面站收到三类话题，状态和电量约 20 Hz，点云约 0.47 Hz。nuc2 日志记录了低优先级整图被新帧覆盖，未见队列拒绝。测试完成后已关闭隔离桥接与发布器。50,000 B/s 仅为制造拥塞的测试值，不是实机任务的带宽预算。

## 使用边界

- 初版尚未按地图块 ID 去重，也没有断链后的应用层确认/重传；若 P3 队列溢出，只记录拒绝。Marker 仅按 FIFO 保序，未实现按 `DELETE`/`ADD` 成组淘汰。P0 没有端到端确认。ZeroMQ 提交次序不等于无线空口调度次序。
- 因此当前不用于飞行任务。启用实际桥接前，需要测量可用 ROS 预算，检验地图块补齐、Marker 显示、断链恢复与 P1/P2 端到端新鲜度。测试期间未连接飞控、雷达或相机，未启动程控、解锁和起飞。
- 如需回退，先停止桥接，再用上述备份目录中的 `bridge_node.cpp` 与 `bridge_node` 恢复 nuc2；恢复后重新确认运行进程和话题。
